HÀ GIA BẢO — PORTFOLIO (GITHUB PAGES READY)

Files:
- index.html
- style.css
- script.js
- assets/projects/ (portfolio images)

Preview:
1. Extract this ZIP.
2. Open index.html in Chrome.

Publish with GitHub Pages:
1. Create a GitHub repository, e.g. ha-gia-bao-portfolio.
2. Upload all files and the assets folder to the repository root (not the ZIP itself).
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch main and folder / (root), then Save.
6. Wait for GitHub Pages to publish and open the URL shown in Settings > Pages.

Notes:
- The portfolio uses Google Fonts and JSZip CDN; internet is needed for those external resources.
- Images included in assets/projects are bundled locally so they display on the public site.
- Local editing controls are hidden in this public build. Changes should be made in the source files and pushed to GitHub.
- Content is based on the information provided by the portfolio owner. Please review employment dates and all project permissions before publishing.
